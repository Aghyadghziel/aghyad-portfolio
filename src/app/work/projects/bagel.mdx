## The brief

Build the front end of the Bagel platform: responsive, high-performance interfaces that hold up on any screen, assembled from components the team could reuse rather than rebuild.

## What I built

**A reusable component set.** Modular UI components in React and Next.js, built so the same patterns could be reused across the product instead of each screen inventing its own.

**Responsive interfaces.** Layouts that work from a narrow phone to a wide desktop, with the mobile case treated as a real design rather than a shrunken desktop.

**Performance.** Interfaces tuned to load and respond quickly — the difference between a product that feels considered and one that feels heavy.

**Design collaboration.** Working directly with the design team from Figma files through to shipped code, and with the backend team on the data those interfaces depend on.

## Notes

This was a front-end engagement on an existing product: consistent components, fast pages, and an interface that stays out of the product's way.
